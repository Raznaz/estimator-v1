Шаг 1: Neon

1. Открой neon.tech → Sign up (войди через GitHub — проще всего).
2. Create project:
  - Name: estimator (любое).
  - Postgres version — оставь по умолчанию.
  - Region — выбери ближе к Frankfurt (AWS eu-central-1), чтобы совпадало с регионом Render из render.yaml → меньше задержка.
3. После создания откроется панель Connection Details (или кнопка Connect). Там увидишь строку подключения. Важно — нужен вариант с пулером:
  - Должна быть включена галочка/таб «Pooled connection» (хост содержит -pooler).
  - Строка вида:
postgresql://<user>:<password>@ep-xxxx-pooler.eu-central-1.aws.neon.tech/<db>?sslmode=require
4. Скопируй эту строку целиком — это будущий DATABASE_URL для Render.

Что мне вернуть

Просто напиши «готово», когда создашь проект и получишь строку.

⚠️ Саму строку с паролем мне в чат не вставляй (это секрет — он пойдёт прямо в дашборд Render, не в репозиторий). Мне достаточно знать, что она у тебя на руках, и я поведу дальше — на Шаг 2 (Render).
